# 菜瓜乐影视 · Android TV

Netflix 风格的 Android TV 客户端项目，计划基于 WebHomeTV / FongMi 的原生播放能力。

## 项目状态

**正在准备 Android 云端构建。** 当前仓库尚未导入完整客户端源码，也没有通过 Android TV 实机验证的 APK。

- 应用名称：菜瓜乐影视
- 计划 Application ID：`com.caiguale.tv`
- 目标：影视首页、搜索、详情、选集、线路切换和原生播放
- 计划构建变体：`LeanbackFullArm64_v8aDebug`

## 安全与许可

不要在公开仓库提交 Cookie、Token、云盘账户、签名私钥、`.env`、`local.properties` 或其他私人凭证。构建依赖和第三方源码需要审查相应许可。上游 GPL 项目改编与分发应遵守其许可证。

此 README 仅用于验证仓库写入权限，不表示 APK 已构建成功。
